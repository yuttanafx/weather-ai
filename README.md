# สมุดบันทึกอากาศ (Vercel)

หน้าเว็บ (`public/index.html`) + API (`api/*.js`) + ฐานข้อมูล Neon Postgres

## ติดตั้ง
1. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub แล้ว Import ใน Vercel (หรือรัน `npx vercel` ในโฟลเดอร์นี้)
2. Vercel → Storage → เพิ่ม **Neon (Postgres)** ผูกกับโปรเจกต์ (ได้ `DATABASE_URL` อัตโนมัติ ตารางสร้างให้เองตอนเรียกใช้ครั้งแรก)
3. Settings → Environment Variables:
   | ชื่อ | ค่า |
   |---|---|
   | `SESSION_SECRET` | สตริงสุ่มยาวอย่างน้อย 16 ตัว (ใช้เซ็นคุกกี้ล็อกอิน) |
   | `SIGNUP_CODE` | รหัสเชิญที่คุณตั้งเอง แจกให้สมาชิกใช้ตอนสมัคร |
   | `ANTHROPIC_API_KEY` | คีย์จาก console.anthropic.com |
   | `CRON_SECRET` | สุ่มสตริงยาวๆ (Vercel ส่งให้ cron อัตโนมัติ) |
   | `ANTHROPIC_MODEL` | (ไม่บังคับ) ค่าเริ่มต้น `claude-sonnet-5-5` |
4. Deploy แล้วเปิดเว็บ กด "สมัครสมาชิก" — **บัญชีแรกจะเป็นแอดมินและไม่ต้องใช้รหัสเชิญ** บัญชีถัดไปต้องกรอก `SIGNUP_CODE`

## ล็อกอินสมาชิก
- ต้องล็อกอินก่อนถึงจะเห็นข้อมูลและเรียก API ได้ (ปุ่มออกจากระบบอยู่มุมขวาบน)
- ถ้าไม่ตั้ง `SIGNUP_CODE` จะปิดรับสมัครหลังมีบัญชีแรก
- รหัสผ่านเก็บแบบ scrypt + salt, คุกกี้ HttpOnly/Secure อายุ 30 วัน, ใส่รหัสผิด 5 ครั้งล็อก 15 นาที
- ยังไม่มีหน้าลืมรหัสผ่าน/ลบสมาชิก ต้องแก้ในตาราง `users` ของ Neon โดยตรง


## ดึงข้อมูลอัตโนมัติ
ในหน้าเว็บ ส่วน "ดึงข้อมูลอัตโนมัติ": เลือกพื้นที่ในฟอร์ม → ค้นหาพิกัด → ตั้งทุกกี่ชั่วโมง → เพิ่ม
ข้อมูลมาจาก Open-Meteo (ฟรี ไม่ต้องใช้คีย์) บันทึกเป็นค่ารายวันของวันนั้น (สูงสุด/ต่ำสุด/ความชื้นเฉลี่ย/ฝนสะสม/ผิวดิน/ความชื้นดิน ณ ตอนที่ดึง)

**ความถี่ของ cron**
- Vercel Hobby: cron รันได้วันละครั้ง ไฟล์ `vercel.json` จึงตั้ง `0 0 * * *` ไว้
- Vercel Pro: เปลี่ยนเป็น `0 * * * *` (ทุกชั่วโมง) ได้ แล้วแต่ละพื้นที่จะดึงตามช่วงเวลาที่ตั้ง (ทุก 1/3/6/12/24 ชม.)
- ใช้ Hobby แต่อยากได้ทุกชั่วโมง: ใช้ `.github/workflows/pull-weather.yml` (ตั้ง secrets `APP_URL`, `CRON_SECRET`)

## หมายเหตุ
- ค่าจาก Open-Meteo เป็นข้อมูลโมเดล/วิเคราะห์ย้อนหลัง ไม่ใช่เครื่องวัดที่จุดของคุณ ความชื้นดินเป็นค่าปริมาตรน้ำ (m³/m³ × 100)
- โค้ดชุดนี้ยังไม่ได้ทดสอบบน Vercel จริง ลอง deploy แล้วดู Logs ถ้ามีข้อผิดพลาด
